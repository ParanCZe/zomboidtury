BO1Z · ORIGINÁLNÍ KISAKBLACK · MOBILE BOOT v2.8.1

Spustit původní BO1Z na mobilu

Tohle není nová zombie hra. Spouští přímo tvoje originální KisakBlack-web.mjs a KisakBlack-web.wasm. Testuje skutečné pracovní vlákno s WebGL2 fallbackem a připojuje dotykové ovládání.

Experimentální port, nikoli potvrzená hratelná verze. Bez originálních balíčků map uložených pro tento web může engine skončit chybou načítání. Původní 2GB WASM na iPhonu může selhat; použij níže staženou low-memory variantu. Pokud web nehlásí crossOriginIsolated: true, pthread start nebude fungovat.
iPhone / iPad: Výběr souborů neomezuji podle přípony, aby šly vybrat i soubory .wasm a .mjs v aplikaci Soubory.

Stahování probíhá postupně po jednotlivých souborech do OPFS /pack-kino. Po přerušení znovu ověří již hotové soubory. Soubory bez dostupných Brotli bloků se zatím přeskočí. Větší soubory nad 128 MB jsou v této verzi také pozastavené kvůli paměti iPhonu.

Test stáhne jen malý vzorek dat, nikoli celou mapu. Před plným stažením (~931 MB) ověříme oprávnění a kapacitu zařízení.
