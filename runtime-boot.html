První start skutečného runtime

Experiment použije tvoje originální soubory KisakBlack-web.mjs a KisakBlack-web.wasm. Bude volat skutečný Emscripten runtime, nikoliv zástupné importy. Vypne automatické spuštění hry a testuje, zda dokončí inicializaci. Zůstane pouze v této kartě; nic neodesílá.

Co se upravuje

Pro diagnostický režim bez main nahradíme pouze obalování importů přes nedostupné JSPI běžnými funkcemi. Pokud bude hra potřebovat asynchronní import, tento test jej nevyřeší. Pro snížení rizika vypneme přednačítání worker poolu; to není funkční náhrada pthreads. Případný úspěch znamená jen úspěšné načtení runtime, nikoli hraní BO1Z.

Upozornění: původní engine rezervuje téměř 2 GiB paměti a Safari může kartu zavřít. Výběr souborů je dobrovolný a soubory zůstávají pouze na zařízení. Test má 15sekundový časový limit, ale při zablokování hlavního vlákna nemusí limit zafungovat.
